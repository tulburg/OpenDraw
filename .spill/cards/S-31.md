## Purpose
Copy doop's agent integrations that OpenDraw does not have yet (server/mcp.ts, server/agentKeys.ts, claude-extension, cursor-plugin, chatgpt-plugin, src/components/ConnectModal.tsx and the Install components). OpenDraw keeps its Paper-compatible tools; doop's tool categories we lack are added in our node model (see Q-15).

## Requirements
1. Connect dialog with a guided setup for Claude Code, Claude (desktop and web), Codex, ChatGPT, Cursor and any MCP client, including one-click Add to Claude, Add to Cursor and Add to Codex where doop has them.
2. In server mode the MCP endpoint is streamable HTTP with OAuth (dynamic client registration, consent screen, refresh tokens), and agent keys (Settings > Agent keys: create, list, revoke) for headless clients as a bearer header. Every call acts as the account that approved it. The desktop app keeps its local bridge.
3. `set_status` and `get_profile`: an agent's one-line status shows in the editor while it works; get_profile names the account.
4. Version history for agents: list a node's or artboard's earlier states and restore one (with the replaced state kept as a version), matching doop's list_frame_versions and restore_frame_version.
5. Comment tools: read comments with replies (filter by artboard and resolved state), reply, resolve, and fetch-and-claim open feedback (doop's get_comments, reply_to_comment, resolve_comment, get_feedback).
6. Asset and web tools: upload_asset, search_icons (Iconify), search_images (Pexels, with a key), search_logos (Brandfetch, with a key), list_backgrounds, view_website and import_webpage.
7. Design guidelines: list, read and write a file's style guides and pinned references, and save decisions (doop's design memory without its distiller, which belongs to the Doop Agent).
8. Each tool keeps doop's read-only, destructive and idempotent annotations and is described in our guide.

## Out of scope
The Doop Agent and its model accounts, image generation (D-9), Linear tools, prototype tools, presence avatars and agent cursors (multiplayer).

## Acceptance checks
- Claude Code adds the server with the dialog's command and completes OAuth in the browser against a server; tools/list includes the new tools.
- An agent key in a bearer header works; revoked, the next call gets 401.
- set_status shows in the editor and clears when empty.
- restore of an earlier version brings it back and keeps the replaced one as a version; one undo in the editor reverts it.
- get_comments, reply_to_comment and resolve_comment round-trip with the editor's comments.
- import_webpage puts a page on the canvas as editable layers.
