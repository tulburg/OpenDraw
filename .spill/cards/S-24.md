## Purpose
The File menu is Electron's default, so Cmd+W closes the whole window instead of the current tab, and there is no Cmd+N for a new file. Zoom commands exist only as canvas keys, with no zoom to selection. These are basic desktop-app expectations.

## Requirements
1. File menu: New File (Cmd+N) creates an untitled file in the current folder of the file browser (or the workspace root) and opens it in a new tab; Open... (Cmd+O) shows the home view; Close Tab (Cmd+W) closes the active tab, and with no tabs left shows the home view instead of closing the window; Close Window (Cmd+Shift+W) closes the window.
2. Duplicate File and Rename File act on the active tab's file, the same as the file browser does (S-13).
3. View menu: Zoom In (Cmd+=), Zoom Out (Cmd+-), Zoom to 100% (Cmd+0), Zoom to Fit (Shift+1), Zoom to Selection (Shift+2), plus the existing reload, dev tools and full screen items. Menu shortcuts show but reach the canvas as today, so typing in fields is not affected.
4. Zoom to Selection fits the selected layers in view with the same padding as Zoom to Fit; with nothing selected it does nothing.
5. The zoom readout in the top bar opens a small menu with the same zoom commands and their shortcuts.

## Out of scope
Recent files menu, multiple windows, printing.

## Acceptance checks
- Cmd+N opens a new untitled tab and the file exists on disk; Cmd+W closes it and the window stays open, showing the previous tab or the home view.
- Shift+2 with a small frame selected centers it and zooms so it fills the view with padding.
- Each View menu item changes the zoom as its shortcut does; clicking the zoom readout lists the same commands.
