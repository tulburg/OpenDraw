The framework for the editor's own UI (panels, top bar, canvas overlays). Paper's get_jsx output is React-style JSX, and React has the largest set of editor-grade libraries. Open pencil uses Vue 3, which only matters if we copy its UI code.

- A. React + TypeScript (recommended)
- B. Vue 3 + TypeScript
- C. Svelte + TypeScript
