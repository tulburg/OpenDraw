D-8 says an image an agent names by absolute path is copied into the design file's own assets. A design today is one .opendraw file (JSON) with no place for assets; images dropped or pasted on the canvas are already stored inside it as data: URLs. So the copy needs a home, and that changes the file format. Meanwhile I am building the rest of S-22 (the opendraw-asset:// name, paper-asset:// as an alias, migrating old files, clear errors, locked in get_node_info).

- A. Inside the .opendraw file: an assets table in the document, and the layer's src reads opendraw-asset://<id> (recommended: one file to move or share, the same as dropped and pasted images today; the file grows by the image size)
- B. A folder beside the design file (Name.assets/), moved and renamed with it (keeps the .opendraw small; sharing a design means sharing the folder too)
- C. One hidden folder for the whole workspace (.opendraw-assets/), each image stored once by content (smallest on disk; a design copied out of the workspace loses its images)
