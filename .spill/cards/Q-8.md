Paper agents write local images as absolute paths (`paper-asset:///Users/name/logo.svg`). Today OpenDraw only accepts paths inside the workspace and refuses the rest (S-17), so these writes fail. Allowing absolute paths raises two things: which files an agent may point at, and whether the design still shows the image after the source file moves or the design is shared.

- A. Copy the image into the design file's own assets when it is written; any file the user can read is allowed (recommended: designs stay self-contained, and an agent can only copy images in, never read other files out)
- B. Reference the file in place, any path the user can read (closest to a plain file URL; images break if the source moves)
- C. Reference in place, but only under the home folder
