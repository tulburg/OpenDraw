## Purpose
Agents design in OpenDraw the way they do in Paper: write HTML with inline CSS onto the canvas, adjust styles, and restructure nodes, while the user watches each change land live.

## Requirements
1. Write tools with Paper's names and arguments: `create_artboard`, `write_html` (`insert-children` and `replace` modes), `update_styles` (batched, returns `ignoredStyles`), `set_text_content`, `rename_nodes`, `move_nodes`, `duplicate_nodes`, `delete_nodes`, `finish_working_on_nodes`.
2. `write_html` turns HTML with inline styles into nodes following Paper's rules: flex, padding and gap layout; absolute positioning; `layer-name` sets the layer name; `<img>`, `<svg>` and `<pre>` are supported; margin, grid, inline display and tables are dropped and reported back.
3. `create_artboard` places the new artboard in the first empty spot on the page, 80 px from its neighbours, defaulting to `display: flex; flex-direction: column`.
4. Every write goes through the document engine (S-3), so each tool call is one undo step.
5. While an agent writes, the nodes it touched show a working indicator on the canvas until `finish_working_on_nodes` or 30 s without a write.
6. Writes made while the user is on another page land on the page named by `pageId` without moving the user's view.

## Out of scope
The clone tag inside `write_html`, AI image generation, local image URLs, tokens, comments, export, files and folders.

## Acceptance checks
- An agent builds a small landing page (artboard, header, three cards) with only these tools; a screenshot matches the HTML rendered in a plain browser.
- `write_html` with margin and a grid container reports both as dropped and still renders the rest.
- Two `create_artboard` calls never overlap and keep 80 px apart.
- Undo after a `write_html` removes exactly what it added.
- The working indicator shows during writes and clears on `finish_working_on_nodes`.
- A write to another page does not change the user's page or viewport.
