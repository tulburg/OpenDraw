In doop, @Doop in Slack starts the Doop Agent, which is left out. Without it, what is Slack for in OpenDraw?

A. Notifications only: new comments, replies and mentions on files are posted to a chosen channel, with links. Recommended: useful with no agent.
B. A. plus link unfurls: pasting an OpenDraw file or element link in Slack shows a live image preview (uses S-33's live image links).
C. Hand a mention to the user's own connected agent (via MCP), which then works in the file.
