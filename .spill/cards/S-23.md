## Purpose
S-6 limited copy and paste to OpenDraw's own layers. Today pasting a screenshot, an SVG icon copied from an icon site, or HTML from a browser or code editor does nothing, and copying layers puts nothing other apps can read on the clipboard. Moving material in and out by clipboard is a basic expectation of a design tool.

## Requirements
1. Pasting an image (PNG, JPEG, GIF, WebP) from the system clipboard adds an image layer at its natural size, scaled down to fit, into the selected container (or the artboard under the viewport center), like the Image tool (S-9).
2. Pasting SVG markup (as text or `image/svg+xml`) adds an SVG layer, sanitized as S-9 does.
3. Pasting HTML (`text/html`, or plain text that is an HTML fragment) converts it with the same rules as `write_html` (S-5, S-8): supported layout and text formatting are kept, and what is dropped (margin, grid, tables and so on) shows in a notice instead of failing silently.
4. Pasting plain text that is not markup adds a text layer with that text.
5. Copying OpenDraw layers also writes `text/html` (the same output as Copy as HTML, S-18) and `text/plain`, so they paste into code editors and other apps; pasting them back into OpenDraw still uses the exact internal format.
6. Each paste is one undo step and selects what it added. Pasting while editing text or typing in a field keeps the normal text paste.

## Out of scope
Pasting Figma or Sketch clipboard data, pasting files from Finder other than images, rich clipboard image export (copy as PNG).

## Acceptance checks
- Paste a PNG from the clipboard: an image layer appears in the selected frame at its natural size; one undo removes it.
- Paste an SVG string: an SVG layer appears; a `<script>` inside it is removed.
- Paste `<div style="display:flex;gap:8px;margin:4px"><p>Hi <b>there</b></p></div>`: a flex frame with a rich text layer appears and a notice reports margin dropped.
- Paste plain text: a text layer with that text.
- Copy a frame, read the system clipboard: `text/html` holds the frame's HTML; pasting it back in OpenDraw gives an identical copy.
