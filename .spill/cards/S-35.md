## Purpose
Part 1 of S-32 (D-13). Move OpenDraw to doop's layout model and add its shape tools (src/components/CanvasDrawing.tsx, ElementMove.tsx, ElementResizeHandles.tsx, FlexLayoutControls.tsx). A shape drawn inside an artboard or frame is a positioned layer; flex layout applies only when the user turns it on, like Figma's auto layout. This replaces S-9 Req 3 and the flex-column default for new artboards, and fixes the flex-by-default problem raised on 2 Nov.

## Requirements
1. Tools with doop's single-key shortcuts: Select V, Hand H, Frame F, Rectangle R, Circle O, Text T, Comment C. None fires while typing in a field.
2. New artboards and drawn frames have no layout; everything drawn, pasted or dropped inside is `position: absolute` where it lands.
3. Moving and resizing a positioned layer changes only its left, top, width and height.
4. A Flex layout control (direction, gap, padding, wrap, alignment) turns flex on for a container; turning it off keeps the children where they were, as positioned layers.
5. Agent-written HTML keeps the layout it declares.

## Acceptance checks
- Draw a rectangle inside a new artboard: it is `position: absolute` at the drawn spot and the artboard has no display: flex.
- Circle O draws an ellipse layer (border-radius 50%).
- Turn on flex for a frame with three positioned children: they flow with the chosen gap; turn it off: they stay where they were, positioned. One undo each.
- write_html with a flex container keeps display: flex and its children unpositioned.
