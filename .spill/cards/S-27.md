## Purpose
D-10: agent-facing names carry OpenDraw's name, with Paper's names kept as accepted aliases so Paper-trained agents still work. S-22 does this for local image URLs; this spec does it for the clone tag and the guide topic from S-17.

## Requirements
1. `write_html` accepts `<x-opendraw-clone node-id="...">` with the same behavior as S-17's clone tag (copy with new IDs, `style` and `layer-name` overrides, a missing ID fails the whole call). `<x-paper-clone>` is still accepted as an alias.
2. The guide topic is `opendraw-mcp-instructions`; `get_guide` also answers `paper-mcp-instructions` with the same text. The guide file is renamed to match.
3. Tool descriptions, the server instructions and the guide text use only the OpenDraw names. Unknown-topic errors list only the OpenDraw topic names.

## Out of scope
The tool names themselves (they stay Paper-compatible), the URL schemes (S-22).

## Acceptance checks
- `write_html` with `<x-opendraw-clone node-id>` and with `<x-paper-clone node-id>` both insert a copy with new IDs.
- `get_guide` returns the same text for `opendraw-mcp-instructions` and `paper-mcp-instructions`.
- `tools/list` descriptions and the server instructions contain no `x-paper-clone` or `paper-mcp-instructions`.
