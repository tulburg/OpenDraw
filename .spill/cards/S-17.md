## Purpose
Paper's agents lean on a few helper tools and HTML extensions that OpenDraw does not have yet: `get_font_family_info` before styling type, `get_guide` for working instructions, `<x-paper-clone>` inside `write_html` to reuse existing layers, and `paper-asset://` URLs for local images. Prompts written for Paper use all four.

## Requirements
1. `get_font_family_info` {fileId, familyNames} reports, per family, whether it is available (installed on this machine, used in the file, or on Google Fonts), and its weights and styles. Families found only on Google Fonts are loaded into the app on demand when first used in a style, so the canvas, screenshots and exports render them; offline, the tool says Google Fonts could not be reached.
2. `get_guide` {topic} returns OpenDraw's own guide text: `paper-mcp-instructions` (how to work with OpenDraw's tools: start with get_basic_info, write in small groups, review with screenshots, tokens, pages, finish_working_on_nodes) and `mobile-status-bar` (paste-ready status bar markup). Unknown topics list the available ones. The guide content lives in one markdown file per topic in the repo.
3. `write_html` accepts `<x-paper-clone node-id="..."></x-paper-clone>`: it inserts a copy of that node with new IDs, and attributes `style` and `layer-name` on the tag override the copy's root style and name. A missing node ID fails the whole call with no change.
4. Image URLs (in `src`, `background-image`, and `update_styles`) accept `paper-asset://<path>`, a path relative to the workspace folder. The app serves these through a protocol handler that refuses paths outside the workspace. Exports, screenshots and thumbnails render them.
5. The styles panel and HTML paste keep `paper-asset://` URLs as written; `get_jsx` returns them unchanged.

## Out of scope
`paper-gen://` AI image generation, Figma import, uploading fonts.

## Acceptance checks
- `get_font_family_info` for "Inter", a family installed on the machine, and "Not A Font" returns available, available (with weights) and unavailable.
- Using a Google Fonts family in `update_styles` renders it on the canvas and in `get_screenshot`.
- `get_guide` returns the instructions topic; an unknown topic lists the topics.
- `write_html` with an `x-paper-clone` of a card inserts a copy with new IDs and the overridden width; with a bad node ID nothing changes.
- An image with `src="paper-asset://images/logo.png"` (a file in the workspace) renders on the canvas and in a screenshot; `paper-asset://../secret.png` does not load.
