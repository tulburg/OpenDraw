## Purpose
Part 5 of S-32 (D-13). Doop's theme picker and frame version history (src/components/ThemePicker.tsx, the frame versions UI).

## Requirements
1. Themes: Light, Dark or System in Settings; System follows the OS.
2. Version history for an artboard from its menu: list earlier states with times, preview one, restore it (the replaced state is kept as a version). Restore is one undo.

## Acceptance checks
- Switch to Dark: the editor chrome is dark and the design is unchanged; System follows the OS setting.
- Edit an artboard twice, open its history, restore the first state: the canvas shows it, the replaced state is listed, and undo brings it back.
