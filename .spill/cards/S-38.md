## Purpose
Part 4 of S-32 (D-13). Doop's layer shortcuts, element menu and search palette (src/components/ElementContextMenu.tsx, CanvasSearchModal.tsx).

## Requirements
1. Shortcuts: Cmd+Shift+H hide and Cmd+Shift+L lock the selection, Alt+Up/Down move a layer in the Layers panel, Cmd+. hides all UI, Cmd+Y redo, Esc deselects. None fires while typing in a field.
2. Element menu and floating toolbar: Copy HTML, Copy selector, Copy link to element (opening the link selects the element on its page).
3. Search palette (Cmd+K on the canvas): find layers, artboards and pages by name or text, and jump to the pick.

## Acceptance checks
- Each shortcut in Req 1 does its action, and none fires in a field.
- Copy link to element, open it in a fresh window: the element is selected on its page.
- Cmd+K, type part of a text layer's text: it is listed, and Enter selects and shows it.
