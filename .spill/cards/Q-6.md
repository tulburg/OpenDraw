S-15 lists AVIF as an export format. Electron's Chromium encodes PNG, JPG and WEBP, but not AVIF (canvas falls back to PNG), so AVIF needs a new dependency. Everything else in S-15 is built without one; this only decides AVIF.

- A. @jsquash/avif: a WebAssembly encoder (libavif), no native build step, runs in the render window (recommended)
- B. sharp: native libvips binding, fast and covers every format, but adds a large native module to package for each platform
- C. Leave AVIF out of S-15 for now and drop it from the format list
