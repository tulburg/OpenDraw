## Purpose
Bring the parts of doop (github.com/kgoedecke/doop, AGPL-3.0, copied under D-12) that OpenDraw lacks: self-hosting with accounts, invites and collaborators, the agent integrations, the canvas editing features, the missing comment, import and export features, and Slack. Code is copied from doop and adapted, not rewritten, and each piece is checked against doop's behavior and tests before it counts as done.

This is the overview. The work is in the part specs drawn under it; this card owns no requirements of its own.

## How the parts fit
- Self-hosted server mode (accounts) comes first: invites, OAuth for agents, email digests and Slack all need a server and accounts. The desktop app keeps working as today with accounts off.
- Invites and collaborators build on accounts.
- Agent integrations: the connect flows and the tools we do not have yet. Tools that need a server (OAuth, agent keys) arrive with server mode; the rest work in the desktop app too.
- Canvas editing: doop's tools, path editing, rulers and guides, and its layout model (shapes are positioned layers; flex only when asked), which also settles the flex-by-default problem raised on 2 Nov.
- Comments, imports and exports: what doop has and we do not.
- Slack.

## Licensing (D-12)
Copied files keep doop's copyright and AGPL notice; doop's license goes in LICENSE-AGPL; NOTICE lists the copied files; the README says the app as a whole is distributed under AGPL-3.0. OpenDraw's own files stay MIT.

## Left out (user's list, 2 Nov)
The Doop Agent, prototypes, multiplayer, the iPhone and iPad apps, workspaces and billing, social sign-in, and everything else not on the add list: Linear, Meta Ads, automations, webhooks, the community gallery, frame approval, image generation (D-9), the GitHub repo import (it runs the Doop Agent), the iOS push and analytics settings.
