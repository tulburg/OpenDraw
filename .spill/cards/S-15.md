## Purpose
Designs have to leave OpenDraw as files. Paper lets users set export settings on any layer and export them from the design panel, and gives agents `export`, `export_combined_pdf` and `get_fill_image`. OpenDraw has screenshots for agents only.

## Requirements
1. Any layer can carry export settings, saved with the file: a list of entries, each with a format (PNG, JPG, WEBP, AVIF, SVG, PDF) and a scale written as Paper does: `1x`, `2x`, `0.5x`, `720p` (height), `512w` (width) or `512h` (height). JPG, WEBP and AVIF have a quality setting.
2. The styles panel has an Export section: add, edit and remove entries, a preview of the first entry, and an Export button that writes one file per entry to a folder the user picks (remembered across launches), named after the layer, with a `@2x`-style suffix when the scale is not 1x.
3. Exports render the layer alone, at its own size times the scale, with tokens applied, the same way `get_screenshot` does. PNG, WEBP and AVIF keep transparency. SVG export embeds the layer as HTML in a `foreignObject` so text stays text.
4. A PDF export is vector: text stays selectable and the page size is the layer's size.
5. MCP `export` {fileId, nodes, pageId?, type?} exports the given node IDs with their own settings (PNG 1x when a node has none), or every node that has export settings when `nodes` is `"nodes-with-exports-only"`. It returns each file's path. Files land in an `Exports` folder next to the workspace unless the user has picked a folder.
6. MCP `export_combined_pdf` {fileId, nodeIds} writes one PDF with one page per node, ordered top to bottom then left to right on the canvas, and returns its path.
7. MCP `get_fill_image` {fileId, nodeId} returns an image node's (or a background-image's) picture as base64 JPEG, scaled down to at most 1568 px on the long side, with the source URL in the metadata; for an SVG node or a node with no image it returns a message pointing to `get_jsx`.

## Out of scope
Video export (mp4, webm), exporting whole pages, print bleed and color profiles, sharing links.

## Acceptance checks
- Adding a `2x PNG` and a `JPG 512w` entry in the panel and pressing Export writes `Card@2x.png` at twice the layer's size and `Card@512w.jpg` 512 px wide.
- A PDF export of an artboard with text has selectable text and the artboard's page size.
- `export` with `"nodes-with-exports-only"` exports exactly the nodes that have settings; with IDs, a node without settings exports as a 1x PNG.
- `export_combined_pdf` with three artboards returns a 3-page PDF in canvas order.
- `get_fill_image` returns JPEG data for an image node and a message for an SVG node.
- Export settings survive a restart and undo removes an added entry.
