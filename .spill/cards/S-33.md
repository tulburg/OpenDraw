## Purpose
Copy what doop's comments, imports and exports do that OpenDraw does not yet (server/commentNotifications.ts, server/mailer.ts, server/webpageImport.ts, server/importer.ts, server/pdfExport.ts, server/previews.ts, src/components/ExportModal.tsx, FrameExportModal.tsx, ImportSources.tsx).

## Requirements
1. Comments panel lists the page's threads, open or resolved, with replies (keep what S-16 has; add what doop has that we lack: canvas-anchored comments next to element comments, Copy link to a thread).
2. Email digest (server mode with SMTP): people who miss a comment on a file they can open get a digest; Settings > Account has an opt-out.
3. Import sources: Website (one page, or discover a site's pages and pick them) and Live app (doop's sync snippet that pushes an app's screens onto a file). Imported pages become editable layers.
4. Export: PNG, JPG and a vector PDF for an artboard or a selection of artboards as one PDF, from the artboard menu and the top bar, with a progress toast and the native save panel in the desktop app.
5. Live image links (server mode): every artboard has a URL like /i/<id>.png?scale=2 (or .jpg) that re-renders when the design changes; it obeys the file's access rules.

## Out of scope
Figma, Canva and PSD import and export (not in doop's open source), the GitHub repo import (it runs the Doop Agent), @mention queuing of agent work.

## Acceptance checks
- A canvas comment and an element comment both list in the panel; resolving one moves it to resolved.
- With SMTP pointing at a test inbox, a missed comment arrives in a digest; after opt-out it does not.
- Import a local test page as Website: its text and images are editable layers.
- Export two artboards as one PDF: two pages, vector text.
- The live image URL updates after an edit, and returns 403 to an account without access.
