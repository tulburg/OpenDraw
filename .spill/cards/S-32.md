## Purpose
Copy doop's canvas editor features (src/components/CanvasDrawing.tsx, PathEditor.tsx, Rulers.tsx, SnapGuides.tsx, ElementMove.tsx, ElementResizeHandles.tsx, FlexLayoutControls.tsx, ElementContextMenu.tsx, CanvasSearchModal.tsx, ZoomControls.tsx, ThemePicker.tsx). It also moves OpenDraw to doop's layout model: a shape drawn inside an artboard or frame is a positioned layer, and flex layout applies only when the user turns it on, like Figma's auto layout. This replaces S-9 Req 3 and the flex-column default for new artboards.

## Requirements
1. Tools with doop's single-key shortcuts: Select V, Hand H, Frame F, Rectangle R, Circle O, Vector path P (Bezier pen: snaps to its own anchors, previews closing the path, Alt skips snapping), Text T, Comment C.
2. Layout model: new artboards and drawn frames have no layout; everything drawn inside is `position: absolute` where it was drawn. A Flex layout control (direction, gap, padding, wrap, alignment) turns flex on for a container; turning it off keeps the children where they were, as positioned layers. Agent-written HTML keeps the layout it declares.
3. Path editing: double-click a path to drag anchors and Bezier handles, switch points between corner and curve, delete points; Alt moves one handle alone; Shift constrains the angle.
4. Rulers and guides: Shift+R toggles rulers; dragging out of a ruler adds a guide; guides belong to the page, undo like any edit, and everything snaps to them within 8 screen pixels.
5. Zoom from 8% to 1600% (doop's range), the pixel grid from 300%, and the zoom menu's 50/100/200% presets and rulers toggle.
6. Shortcuts: Cmd+Shift+H hide and Cmd+Shift+L lock the selection, Alt+Up/Down move a layer in the Layers panel, Cmd+. hides all UI, Cmd+Y redo, Esc deselects.
7. Element menu and floating toolbar: Copy HTML, Copy selector, Copy link to element (opening the link selects the element on its page).
8. Search palette (Cmd+K on the canvas): find layers, artboards and pages by name or text.
9. Themes: Light, Dark or System in Settings.
10. Version history for an artboard from its menu: preview and restore earlier states.

## Out of scope
Prototype mode and interactions, phone and tablet touch handling, presence and follow.

## Acceptance checks
- Draw a rectangle inside a new artboard: it is `position: absolute` at the drawn spot and the artboard has no display: flex.
- Turn on flex for a frame with three positioned children: they flow with the chosen gap; turn it off: they stay where they were, positioned.
- Draw a closed path with the pen, then move an anchor and switch a point to a curve; one undo each.
- Drag a guide out of the ruler; a dragged frame snaps to it within 8 px; undo removes the guide.
- Copy link to element, open it in a fresh window: the element is selected on its page.
- Each shortcut in Req 6 does its action and none fires while typing in a field.
