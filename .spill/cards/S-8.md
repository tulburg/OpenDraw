## Purpose
Text layers hold plain text today, so `write_html` and `set_text_content` flatten formatting like a bold word inside a paragraph, which Paper keeps. Text layers should hold rich text, and the user should edit text in place on the canvas.

## Requirements
1. A text layer stores its content as a list of spans, each with text and an optional style limited to what Paper allows on text runs: color, font family, size, weight, style, letter spacing, line height, text transform, text decoration, `-webkit-text-stroke`, and background color or image only together with `background-clip: text`. Plain text layers stay a single span; files from earlier versions load unchanged.
2. `write_html` and `set_text_content` keep inline formatting (`<b>`, `<em>`, `<a>`, `<span style>` and the like) as spans instead of flattening it; properties a span cannot have (padding, margins, sizes, positioning) are dropped and reported.
3. `get_jsx` exports spans as nested `<span style>`; `find_nodes` text search matches across spans; `update_styles` on a text layer applies to the whole layer, spans included, as Paper describes.
4. Double-clicking a text layer on the canvas edits it in place: typing, selecting, cmd/ctrl + B, I and U toggle formatting on the selected range, Enter adds a line break, Escape or clicking away commits. The commit is one undo step; cmd/ctrl + Z while editing undoes typing first.
5. Pasting into a text layer keeps supported formatting from HTML clipboard content and drops the rest.
6. Rich text renders the same on the canvas, in screenshots and in the render window.

## Out of scope
Lists and bullets, links that navigate, per-span hover states, spell check UI, font loading beyond installed and web fonts.

## Acceptance checks
- `write_html` with `<p>Ship <b>fast</b> and <span style="color: red">safe</span></p>` creates one text layer with three spans and reports nothing dropped; a screenshot matches the same HTML in a plain browser.
- A span with `padding: 4px` is reported as dropped and the text still renders.
- `get_jsx` round-trips the spans; `find_nodes` with "fast and" finds the layer.
- Double-click, select a word, cmd + B, Escape: that word is bold in the saved file, and one undo removes the change.
- A file saved by the current version (plain `text`) opens unchanged.
