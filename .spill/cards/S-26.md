## Purpose
S-9 left image fill modes out of scope. An image layer placed in a sized frame can only stretch, and replacing a picture means deleting and redrawing the layer, losing its styles and position. CSS already has the controls (`object-fit`, `object-position`, `background-size`), so this is mostly styles panel work.

## Requirements
1. For image layers, the styles panel shows an Image group: Fit (Fill = `object-fit: cover`, Fit = `contain`, Stretch = `fill`, Original = `none`), position (`object-position`, with a 3x3 picker plus free values), and a Replace button.
2. For frames with a `background-image`, the same group shows Fit as `background-size` (cover, contain, 100% 100%, auto), position as `background-position`, and repeat as `background-repeat`.
3. Replace opens the file picker (or takes a dropped file on the layer) and swaps the image, keeping the layer's ID, name and styles. One undo step.
4. Dropping an image file onto an existing image layer while holding Alt/Option replaces it instead of adding a new layer.
5. `update_styles` and `get_jsx` carry these properties as written; `get_computed_styles` reports them.

## Out of scope
Cropping by handles, filters and adjustments beyond raw CSS, masks.

## Acceptance checks
- Set Fit to Fill on an image in a 200 x 200 frame: `object-fit: cover` is written and the screenshot shows no distortion.
- Picking the top-left cell writes `object-position: left top`.
- Replace keeps the layer ID and styles and changes only the image; one undo restores the old image.
- A frame with a background image shows background-size choices that write the expected CSS.
