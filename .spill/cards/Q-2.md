Because the canvas renders real CSS, the shell's web engine is the renderer. Electron ships Chromium on every platform, so designs look the same everywhere and page capture for screenshots and export is built in, at about 100 MB. Tauri is ~15 MB and is what open pencil uses, but it renders with WebKit on macOS and WebView2 on Windows, so the same CSS can render differently per platform.

- A. Electron: one rendering engine everywhere (recommended)
- B. Tauri: small app, platform web engines
