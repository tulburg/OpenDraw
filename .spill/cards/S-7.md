## Purpose
The styles panel is read-only. The user should edit the selected layers' CSS from it, grouped the way Paper's design panel is, while CSS stays the source of truth: every control writes a CSS property, and anything without a control can still be edited as raw CSS.

## Requirements
1. The panel shows the selection's styles in groups: Layout (display, flex direction, wrap, align items, justify content, gap, padding), Size (width, height, min/max, with Fixed, Hug = `fit-content`, Fill = `flex: 1` or `100%` depending on the parent), Position (absolute toggle, left/top/right/bottom, z-index), Fill (background color, background image URL, opacity), Border (width, style, color, radius per corner), Shadow (box-shadow as an editable list), and Text (font family, size, weight, line height, letter spacing, color, alignment, decoration, transform) for text layers.
2. Number fields accept units and math (`16`, `1.5em`, `24 * 2`), support arrow up/down (shift for 10) and dragging the label to scrub.
3. A color picker with hex, rgb and hsl input, alpha, and an eyedropper; colors already used in the file are offered as swatches.
4. A raw CSS view lists every property on the layer, editable as text; unknown or custom properties (including `--tokens`) are kept as written.
5. With several layers selected, each field shows the shared value or "Mixed", and an edit applies to all of them.
6. Edits go through the document engine: each committed change (Enter, blur, end of a scrub) is one undo step; scrubbing updates the canvas live but records one step. Properties the engine drops (`ignoredStyles`) show an inline note with the reason instead of failing silently.
7. The font family list comes from fonts installed on the machine, with families already used in the file first.

## Out of scope
Design token management (a later spec), a gradient editor beyond raw CSS, component variants, layer visibility and lock toggles.

## Acceptance checks
- Changing padding to `24` writes `padding: 24px`; one undo restores the old value.
- Setting Size to Hug on a flex child writes `width: fit-content`; Fill writes `flex: 1` in a row parent.
- Typing `margin: 10px` in the raw CSS view shows the "margin is not supported" note and leaves the document unchanged.
- With two layers selected and different backgrounds, Fill shows "Mixed"; setting a color applies to both in one undo step.
- Scrubbing font size from 16 to 40 updates the canvas live and records a single undo step.
