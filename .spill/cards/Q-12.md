You want doop's code copied directly and OpenDraw's MIT license kept, since OpenDraw is not for financial use. AGPL-3.0 applies whether or not anyone makes money, so copied doop code cannot be relabeled MIT. What can stay MIT is OpenDraw's own code: MIT code may be combined with AGPL code. Our repo (tulburg/OpenDraw) is already public, so AGPL's main duty, offering the source to anyone who uses the app or a self-hosted server, is already met. This is not legal advice.

- A. Copy doop's code directly. OpenDraw's own files stay MIT; copied doop files keep doop's copyright and AGPL notice, with doop's license in LICENSE-AGPL and a NOTICE saying which files came from doop; the README says the app as a whole is distributed under AGPL-3.0 because it includes doop code (recommended: copying starts now and nothing of ours is relicensed)
- B. Don't copy code: use doop as a reference only and write our own, so everything stays MIT (slower, more tokens)
- C. Ask doop's maintainer for permission to use his code under MIT, and work as in B until he agrees
