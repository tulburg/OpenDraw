## Purpose
Opening OpenDraw for the first time gives a desktop window with a working canvas and a first artboard, so every later feature (drawing, styles, files, the MCP server) has a place to live. Documents are CSS-native from day one: an artboard is a real DOM element with CSS styles, not a Figma-style node.

## Requirements
1. One dev command (`bun run dev`) opens OpenDraw as a desktop window titled "OpenDraw", 1440x900 by default, minimum 960x600. Size and position are remembered across launches.
2. The window has four regions: a top bar showing the file name, a layers panel on the left, the canvas in the middle, and a styles panel on the right. Both panels show an empty state when nothing is selected.
3. The canvas is unbounded and can be panned (trackpad scroll, space + drag, middle-mouse drag) and zoomed (pinch, cmd/ctrl + scroll, cmd/ctrl + plus, minus, 0 for 100%, shift + 1 to fit). Zoom runs from 10% to 6400% and the current level shows in the top bar.
4. Artboards render as real DOM elements with their CSS styles, at the canvas zoom level, with their name drawn above them.
5. Clicking an artboard selects it (outline plus the layers panel highlights it); clicking empty canvas or pressing Escape deselects.
6. First run: when no documents exist, OpenDraw creates an untitled file in the local workspace folder (default `~/Documents/OpenDraw`) with one page and one 1440x900 "Desktop" artboard with a white background, centered and zoomed to fit.
7. Later launches reopen the last file at its last viewport (pan and zoom) instead of creating a new one.
8. The UI follows the OS light or dark theme.

## Out of scope
Drawing tools, style editing, undo, multiple files or tabs, the files and folders browser, export, the MCP server, collaboration. Each gets its own spec.

## Acceptance checks
- Clean profile (no workspace folder): launch shows the window, the layout from Req 2, and one fitted Desktop artboard; the file exists on disk.
- Relaunch: the same file opens at the same pan and zoom, and the window keeps its size and position.
- Pan and zoom with each input in Req 3; the zoom readout matches; zoom stops at 10% and 6400%.
- The artboard is a DOM element whose computed width, height and background match its stored CSS.
- Select and deselect by click and Escape; the layers panel follows.
- Switch the OS theme: the UI follows.
- Resize the window below the minimum: it stops at 960x600.
