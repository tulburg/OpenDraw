Paper's tools need things only the running app has: computed styles and screenshots come from the canvas, and the user should watch agent edits land live. A standalone server could edit files with the app closed, but would have to fake layout and could not take screenshots.

- A. Inside the app: the Electron main process serves MCP on 127.0.0.1, plus a stdio bridge command for Claude Code (recommended)
- B. A standalone process that reads and writes .opendraw files directly
- C. Both: in the app when it is running, falling back to file-only tools when it is not
