Doop's agent tools work on frames as whole HTML documents (read_frame, update_frame). Ours are Paper-compatible and work on nodes (write_html, update_styles). S-31 adds doop's tool categories we lack (versions, comments, assets, web import, guidelines). How?

A. Add them in our node model with Paper-style names and arguments; doop's frame tools are not copied. Recommended: one consistent tool set, Paper wins ties.
B. Copy doop's tools as they are, beside ours, so doop prompts work unchanged.
