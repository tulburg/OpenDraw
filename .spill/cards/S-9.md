## Purpose
Today new layers only come from agents or paste. The user needs a toolbar to draw artboards, frames, text and images directly on the canvas, as in Paper, with every new layer written as plain CSS.

## Requirements
1. A toolbar on the canvas shows the tools Select (V), Hand (H), Artboard (A), Frame (F), Text (T) and Image (I). The active tool is highlighted; each key switches to its tool; Escape returns to Select. Hovering a tool shows its name and shortcut.
2. Artboard tool: dragging on empty canvas draws an artboard (`left`, `top`, `width`, `height` in px, white background); a click without dragging places a 1440 x 900 artboard at the cursor.
3. Frame tool: dragging inside an artboard or frame draws a frame in the deepest container under the start point. In a flex container it is appended as a flex child with the drawn `width`/`height`; otherwise it is `position: absolute` at the drawn spot. A click places a 100 x 100 frame. New frames get a light gray background so they are visible.
4. Text tool: a click inside a container adds an auto-width text layer and starts editing it in place (S-8); a drag sets a fixed width. Leaving the editor with no text removes the layer and adds no undo step.
5. Image tool: opens a file picker (png, jpg, gif, webp, svg); the image is placed at its natural size (scaled down to fit the target container) at the click point, stored as a data URL, or as an SVG layer for .svg files. Dropping an image file on the canvas does the same.
6. While drawing, the canvas shows the rectangle being drawn and its size label; shift keeps a square, alt draws from the center. Nothing is written until the pointer is released.
7. After a layer is drawn it is selected and the tool returns to Select (holding the tool's key while drawing keeps it).
8. Each drawn layer is one undo step and appears in the layers panel and to agents (`get_tree_summary`, `get_jsx`) like any other layer.

## Out of scope
Shapes beyond frames (ellipse, line, pen), rotation (S-10), snapping while drawing (S-11), image cropping and fill modes.

## Acceptance checks
- Pressing V, H, A, F, T, I switches the highlighted tool; Escape returns to Select.
- Drawing a 300 x 200 frame inside a non-flex artboard writes `position: absolute` with the drawn `left`/`top`/`width`/`height` at zoom 0.5 and 2; one undo removes it.
- Drawing a frame inside a flex column appends it as the last child with the drawn size and no positioning.
- Text tool: click, type "Hello", Escape gives a text layer "Hello" in the saved file; click and Escape with no text leaves the document unchanged.
- Placing a PNG gives an image layer at its natural size; placing an SVG gives an SVG layer.
- An agent's `get_jsx` on the artboard shows each drawn layer.
