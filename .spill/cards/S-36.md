## Purpose
Part 2 of S-32 (D-13). Doop's vector pen and path editor (src/components/CanvasDrawing.tsx, PathEditor.tsx).

## Requirements
1. Vector path tool P: a Bezier pen that snaps to its own anchors, previews closing the path, and skips snapping with Alt. A path is an SVG layer, positioned like any shape.
2. Double-click a path to edit it: drag anchors and Bezier handles, switch points between corner and curve, delete points; Alt moves one handle alone; Shift constrains the angle. Esc or a click outside leaves editing.

## Acceptance checks
- Draw a closed path with the pen; it is one layer whose SVG matches the clicks.
- Move an anchor and switch a point to a curve; one undo each.
- Delete a point; the path stays closed.
